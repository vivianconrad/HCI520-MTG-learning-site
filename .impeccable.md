## Design Context

### Users

Complete beginners to Magic: The Gathering with no card game background. Encountered during structured self-paced learning sessions, likely on desktop. Context: educational and exploratory, never competitive or time-pressured.

### Brand Personality

Scholarly + Welcoming. The interface should feel like a well-produced educational exhibit or illustrated textbook: trustworthy, structured, but approachable and never intimidating. Not arcane or elitist.

### Aesthetic Direction

Dark navy base with warm gold accents and parchment content areas (OKLCH tokens in `src/styles/tokens.css`). Cinzel for headings (ceremonial weight without being exclusionary), Literata for body (scholarly long-form reading). The palette draws from MTG's fantasy heritage, but the tone is educational, not mystical. Dark theme is correct: MTG players engage in low-light environments at the game table.

### Design Principles

1. **Never intimidate**: Every element should lower the barrier to learning, not raise it.
2. **Structured clarity**: Clear visual hierarchy and consistent labelling helps beginners navigate confidently.
3. **Purposeful ornament**: Decorative elements (gold borders, corner marks) earn their place by reinforcing craft and care, not decoration for its own sake.
4. **Capable, not clever**: Design for practical understanding. Users should leave feeling they can play a real game, not that they've decoded something mystical.
5. **Spatial breathing**: Generous spacing and rhythm. Never cramped, never floating.

### Extracted system (implementation)

Shared styles — import order in `src/index.css`:

| Layer | File | Purpose |
| ----- | ---- | ------- |
| Tokens | `tokens.css` | OKLCH colors, surfaces, type scale, spacing |
| Layout | `layout.css` | `.screen-shell` centered navy screens |
| Frame | `parchment-frame.css` | Parchment card, breadcrumb, heading, actions, muted hints |
| Controls | `buttons.css` | `.btn` + screen `*__button` variants |
| Responsive | `responsive.css` | Mobile frame/heading/button adjustments |

**Screen CSS rule**: only screen-specific content (heroes, forms, lesson widgets). Never duplicate frame, heading, paragraph, or button base styles.

**Hint surfaces** (prefer tokens over raw rgba):

- `--surface-hint-warm-bg` / `--surface-hint-border` — subtle callouts on parchment
- `--surface-on-navy-bg` / `--surface-on-navy-border` — hints on navy (e.g. pre-test recovery)
- `--surface-callout-bg` / `--surface-callout-border` — curiosity acknowledgements

**Components to reuse**: `CuriosityNote`, `LessonActions`, `PageLayout`, `KeywordTooltip`, `ParchmentFrameSkeleton`.
